# RecoveryApp — On-Demand Roadside Assistance & Towing SaaS

## Overview
**RecoveryApp** is a turnkey, white-label Progressive Web App (PWA) designed for roadside assistance, vehicle recovery, and towing dispatch management. Built with a modern, lightweight tech stack, it is ready for instant deployment and immediate commercialization.

---

## Key Features
* **Client Booking App:** Live GPS map integration, instant service selector (Flatbed Tow, Battery Boost, Flat Tire, Fuel Delivery), automated fare calculation based on distance, and real-time dispatch tracking.
* **Tow Operator Console:** Online/offline status toggle, incoming request alert cards, estimated payout calculator, and step-by-step job status updates.
* **Admin Dashboard:** Real-time metrics for Gross Merchandise Value (GMV), automated platform commission splits, and a live base fare/rate editor.
* **Multi-Currency Ready:** Seamless switching between USD ($), EUR (€), and local currencies (CLP).

---

## Tech Stack & Architecture
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6+).
* **Mapping & Location:** Leaflet.js / OpenStreetMap (easily swappable for Google Maps API or Mapbox).
* **Icons:** Lucide Icons.
* **Hosting / Deployment:** Optimized for instant 1-click deployment on **Vercel**, Netlify, or GitHub Pages.

---

## Quick Deployment Guide (Vercel)
1. Fork or upload this repository to your GitHub account.
2. Log in to [Vercel](https://vercel.com) and click **Add New Project**.
3. Import your `recoveryapp` repository.
4. Keep default settings (Framework Preset: Other / Static) and click **Deploy**.
